# NsEko（中文名：栖声回响)

> 主要用于日常工作、学习、生活等多场景的录音、回放、声控自动回复，包括对环境噪音、异响录音的存证、原声回放。
> 此仓库仅用于发布更新信息和文档，源代码不在此处开放。
