# NsEko（中文名：栖音回响)

> 主要用于日常工作、学习、生活等多场景各种声音的录音、回放、声控自动回复，包括对环境噪音、异响录音的存证、原声回放。  
> 主要功能包括声音监测与反馈、音频录制与播放、单工/双工回响、日志，另外：  
·为适应微弱声音的处理，加入了实时降噪功能，可根据不同输入设备进行选择适配，比如通过压电陶瓷片放大能够采集微弱振动声音等。  
·为满足双工边采边放中可能产生的回声效应，增加了回声消除功能（测试）。  

> 此仓库仅用于发布更新信息和文档，源代码不在此处开放。
